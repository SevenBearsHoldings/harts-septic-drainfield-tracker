One-time setup required

This app saves to your own Google Sheet. Complete these steps once, then paste your script URL below.

  1. Go to script.google.com → click New project
  2. Delete the default code, paste in the contents of harts_septic_apps_script.gs
  3. Click Save (disk icon), then Deploy → New deployment
  4. Type: Web app · Execute as: Me · Access: Anyone
  5. Click Deploy, authorize when prompted, then copy the Web app URL
